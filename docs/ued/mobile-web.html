帮我分析这段 Python 代码的性能瓶颈：

def find_duplicates(lst):
    result = []
    for i in range(len(lst)):
        for j in range(i+1, len(lst)):
            if lst[i]==lst[j] and lst[i] not in result:
                result.append(lst[i])
    return result
Pi · 2.5-pro

这段代码有两个性能瓶颈：

  • O(n²) 双重循环：嵌套遍历所有元素对
  • O(n) 的 not in：result 是列表，每次检查又是线性扫描

优化方案 — 用集合降到 O(n)：

def find_duplicates(lst):
    seen, result = set(), set()
    for item in lst:
        if item in seen:
            result.add(item)
        else:
            seen.add(item)
    return list(result)
