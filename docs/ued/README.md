# pi-chat UED 界面原型

> 本目录包含 pi-chat 聊天应用三端界面原型（HTML Prototype），可直接用浏览器打开预览。

## 什么是 UED？

**UED** = User Experience Design（用户体验设计），国内大厂（阿里、百度等）设计团队常叫 UED 部门。业界更通用的拆法：

| 术语 | 全称 | 职责 |
|---|---|---|
| UX / UE | User Experience | 用户体验整体设计（交互逻辑、信息架构、用户旅程） |
| UI | User Interface | 界面视觉设计（配色、排版、组件样式） |
| UED | User Experience Design | UX + UI 统称，偏团队/部门命名 |
| IXD | Interaction Design | 交互设计，偏行为逻辑与动效 |

## 业界画界面原型的常见方式

| 保真度 | 叫法 | 典型工具 | 用途 |
|---|---|---|---|
| 低保真 | 线框图 Wireframe | 纸笔、Balsamiq、Whimsical | 快速验证布局逻辑，不关心视觉 |
| 中保真 | Mockup | Figma、Sketch、Adobe XD | 有配色和真实尺寸，不可点 |
| 高保真 | Prototype | Figma、Axure RP、Principle | 可点击跳转、有动效，接近最终产品 |
| 代码级 | HTML Prototype | 手写 HTML/CSS | 浏览器直接跑，开发可复用，可进版本管理 |

本目录使用的是**代码级原型**——介于中保真和高保真之间。

## 文件说明

| 文件 | 说明 | 分辨率基准 |
|---|---|---|
| `index.html` | UED 总览页（设计说明 + 导航） | 响应式 |
| `desktop-web.html` | 桌面网页端原型（双栏布局） | 1440 × 900 |
| `mobile-web.html` | 手机网页端原型（单栏 + 抽屉） | 375 × 812 (iPhone) |
| `mobile-app.html` | 手机 APP 端原型（聊天页 + 设置页） | 360 × 760 (Android) |

## 预览方式

直接用浏览器打开任一 `.html` 文件即可，无需启动服务器。每个原型页面都是自包含的（内联 CSS），可独立分享。

## 三端布局差异

| 维度 | 桌面 Web | 手机 Web | 手机 APP |
|---|---|---|---|
| 布局 | 双栏（侧边栏+主区） | 单栏+抽屉 | 单栏+抽屉 |
| 侧边栏 | 常驻/可拖拽宽度 | 左滑抽屉 | 左滑抽屉 |
| 输入栏 | 底部固定，多行展开 | 底部固定，单行+展开 | 底部固定，键盘自适应 |
| 消息样式 | 全宽文本流 | 全宽文本流 | 气泡式（左右区分） |
| 快捷键 | Ctrl+M/N/K/B 等 | 无（触控） | 无（触控） |
| 图片预览 | Lightbox 点击放大 | 点击全屏查看 | 点击全屏查看 |

## 设计规范

### 配色（暗色主题）

| 变量 | 色值 | 用途 |
|---|---|---|
| `--bg` | #0f0f0f | 全局背景 |
| `--surface` | #18181b | 卡片/侧边栏背景 |
| `--surface2` | #27272a | 次级表面 |
| `--accent` | #6366f1 | 主强调色（按钮、链接） |
| `--accent2` | #818cf8 | 次强调色 |
| `--text` | #e4e4e7 | 主文字 |
| `--text-dim` | #71717a | 次要文字 |
| `--green` | #22c55e | 连接状态/成功 |

### 间距与圆角

- 基础间距单位：4px / 8px / 12px / 16px / 24px
- 卡片圆角：8px
- 按钮圆角：8px
- 气泡圆角：16px（尾部 4px）
- 胶囊/徽章圆角：20px

## 开发复用

原型中的 CSS 变量和组件类名尽量与 `clients/web/public/style.css` 保持一致，方便开发时直接参考复用。
