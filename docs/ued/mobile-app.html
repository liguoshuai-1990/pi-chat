帮我分析这段代码的性能瓶颈：
def find_dup(lst):
    r=[]
    for i in range(len(lst)):
        for j in range(i+1,len(lst)):
            if lst[i]==lst[j] and lst[i] not in r:
                r.append(lst[i])
    return r

两个瓶颈：
1. O(n²) 双重循环
2. O(n) not in 检查（列表线性扫描）

优化 — 用集合降到 O(n)：
def find_dup(lst):
    seen, r = set(), set()
    for x in lst:
        if x in seen: r.add(x)
        else: seen.add(x)
    return list(r)
