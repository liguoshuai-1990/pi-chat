📖 UED 是什么？

术语全称职责
UX / UEUser Experience用户体验整体设计：交互逻辑、信息架构、用户旅程
UIUser Interface界面视觉设计：配色、排版、组件样式
UEDUser Experience DesignUX + UI 统称，国内大厂常作为设计团队/部门命名
IXDInteraction Design交互设计，偏行为逻辑与动效

🎨 业界画界面原型的常见方式

保真度叫法典型工具用途
低保真线框图 Wireframe纸笔、Balsamiq、Whimsical快速验证布局逻辑，不关心视觉
中保真MockupFigma、Sketch、Adobe XD有配色和真实尺寸，不可点
高保真PrototypeFigma、Axure RP、Principle可点击跳转、有动效，接近最终产品
代码级HTML Prototype手写 HTML/CSS浏览器直接跑，开发可复用，可进版本管理
本目录用的是「代码级原型」——介于中保真和高保真之间。优点：无需 Figma 账号、可直接浏览器打开、可进 Git 版本管理、开发可直接参考复用 CSS。缺点：不如 Figma 灵活，改布局需改代码。

🖥️ 三端原型预览

🖥️
桌面网页端
侧边栏 + 主聊天区双栏布局，支持拖拽调整侧边栏宽度，键盘快捷键
分辨率基准：1440 × 900
📱
手机网页端
单栏布局，侧边栏抽屉式弹出，底部固定输入栏，触控优化
分辨率基准：375 × 812 (iPhone)
📲
手机 APP 端
原生 App 风格，顶部导航栏 + 消息列表 + 底部输入，含设置页
Android / HarmonyOS 通用

📝 使用说明

预览方式：直接用浏览器打开任一 .html 文件即可，无需启动服务器。每个原型页面都是自包含的（内联 CSS），可独立分享。
开发复用：原型中的 CSS 变量和组件类名尽量与 clients/web/public/style.css 保持一致，方便开发时直接参考。
